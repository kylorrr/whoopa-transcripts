To answer your questions based on our knowledge base:

1. How it works: A PCIe DMA (Direct Memory Access) card is installed in your main gaming PC (Target PC). This card reads the system memory (RAM) independently of the CPU and sends it to a secondary PC (Radar/Cheat PC) via a USB connection. Because the software and radar run entirely on the secondary PC, it is completely invisible to software-based anti-cheats on the Target PC, provided the DMA card uses a secure, custom 1:1 emulated firmware.

2. Does it work for all games? DMA itself is a hardware technology. However, to use it with specific games, you need compatible firmware matched to the game's anti-cheat system:
- Valorant (VGK / Vanguard): Requires ELYRA VGK, PRIVATE, or SLOT.
- Rust, Apex Legends, Fortnite (EAC): Requires ELYRA EAC, PRIVATE, or SLOT.
- R6 Siege, Tarkov (BE / BattlEye): Requires ELYRA EAC, PRIVATE, or SLOT.
- Call of Duty (Ricochet): Requires ELYRA EAC, PRIVATE, or SLOT.
- FaceIT: Requires ELYRA PRIVATE or SLOT.
- CS2 / General (VAC/Other): Any firmware we sell is sufficient.

3. Is it a cheat? A DMA card is a piece of hardware technology used to read memory. However, when paired with a secondary PC running radar or overlay software (firmware), it is commonly used to bypass anti-cheat systems and run external software or assists.
